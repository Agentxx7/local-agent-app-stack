# Operator card loop

1. Discuss freely with the advisor.
2. Identify one concrete next outcome.
3. Write a short copyable card with boundaries and evidence.
4. Let the operator choose the working agent.
5. Execute only that card.
6. Return report and evidence without self-approval.
7. Review optionally with a specialist chosen by the operator.
8. Return evidence to the advisor and record the operator decision.
9. Create another card only from the reviewed actual state.
