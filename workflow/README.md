# Workflow

This directory documents the template's normal conversation-driven, operator-controlled,
card-based working model. The operator owns decisions, chooses the advisor and work agent, and
may request extra review when useful. These documents describe a process; they do not automate
agent routing, approval, branch protection, or promotion.

- `operator-tdd-card-loop.md` describes the card lifecycle and evidence handoff.
- `two-branch-model.md` defines protected `main` plus one short-lived branch per active card.
