# Architecture

No application architecture is selected by this skeleton.

For a real project, document component boundaries, dependency direction, data ownership,
interfaces, runtime topology, deployment, and important constraints here. Record significant
choices with `templates/architecture-decision-template.md`.

Also document how architecture constraints can be checked, which tests reach each production
boundary, and which state or process owner is authoritative. The template's branch and evidence
model does not select an application architecture or verification tool.
