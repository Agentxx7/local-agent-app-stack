# Agent operating policy

Agents operate only on an operator-selected, bounded card. They must preserve unrelated work,
report assumptions, remain within declared scope, and fail closed when required authority or
evidence is missing.

Agents do not choose themselves, dispatch other agents by default, invent approval, or report
`KLAR` on automated evidence alone. Any handoff names the exact scope, current state, evidence,
open risks, and next required operator decision.

Repository state, secrets, private paths, production data, destructive actions, external writes,
process creation, and publication require the authority stated by the card and project policy.
