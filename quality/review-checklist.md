# Review checklist

- [ ] Scope and stated outcome match the diff.
- [ ] Unrelated or unexplained changes are absent.
- [ ] Assumptions and deferred decisions are explicit.
- [ ] Tests support their claims and reach relevant production paths.
- [ ] State, processes, dependencies, and sensitive data were considered where applicable.
- [ ] Failure handling and cleanup match the project context.
- [ ] Documentation and evidence identify the verified commit.
- [ ] Implemented, tested, verified, accepted, committed, pushed, and released are not conflated.
- [ ] Remaining limitations are reported for operator decision.
