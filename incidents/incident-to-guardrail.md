# Incident-to-guardrail method

1. Establish the incident from preserved evidence.
2. Identify the narrow failure mechanism, not only the symptom.
3. Compare it with existing policy, tests, runtime checks, and operator review.
4. State honestly whether existing enforcement would have stopped it.
5. Add the smallest general prevention or detection slice.
6. Add positive and negative regression evidence.
7. Record the remaining gap and operator decision.
