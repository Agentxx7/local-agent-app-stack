# Task card authoring
## Use when
The operator has selected a concrete next outcome.
## Do not use when
The problem still requires analysis or no decision exists.
## Required context
Goal, base state, allowed scope, boundaries, evidence, and report needs.
## Procedure
Write one outcome, exact scope, hard boundaries, verification, and report contract.
## Constraints
Do not bundle unrelated work, choose an agent, or imply approval.
## Expected output
A short directly copyable card.
## Evidence requirements
Tie acceptance criteria to observable evidence.
## Stop conditions
Stop if scope or authority cannot be made explicit.
## Handoff
Return the card to the operator for agent selection.
