# Skills

This is an optional reusable work library for agents selected by the operator. Choose only skills
relevant to the current card; running every skill is neither required nor desirable. A skill adds
instructions, not authority, approval, routing, or a technology choice.

For code cards, `test-driven-implementation` guides RED/GREEN/REFACTOR and
`production-path-verification` connects claims to real affected paths. Use either only when the
card and project context make it relevant; neither skill is routed automatically.
